Bantuan & panduan
Petunjuk langkah demi langkah untuk menghubungkan Laragon, membuat proyek, memasang tools, dan mengatasi masalah umum.

▶
1. Mulai dalam 3–5 menit
Urutan yang disarankan saat pertama kali membuka SXL Cover.
  1. Hubungkan instalasi.
    Buka Pengaturan → Integrasi Laragon → Pilih folder. Pilih folder yang berisi laragon.exe dan biasanya memiliki folder bin, etc, data, dan www.
  2. Periksa hasil deteksi.
    Buka Alat developer dan tekan Periksa ulang. Jika path atau runtime tidak ditemukan, pastikan folder yang dipilih benar.
  3. Jalankan layanan.
    Buka Layanan, pilih Apache atau Nginx sebagai web server, lalu klik Mulai stack. Jangan menjalankan Apache dan Nginx pada port yang sama secara bersamaan.
  4. Buka proyek lokal.
    Di Proyek, gunakan Buka URL. Proyek mungkin memerlukan virtual host/hostname yang sesuai; tombol URL hanya membuka alamat, tidak otomatis mengubah konfigurasi DNS atau file hosts.
  5. Pastikan log bersih.
    Jika halaman tidak tampil, buka Log & aktivitas dan periksa error web server atau port yang sedang digunakan.

              
▤
2. Mengelola proyek
Membuat, mendaftarkan, dan membuka folder proyek tanpa menghapus file.
  • Buat proyek baru: pilih template PHP sederhana, HTML statis, atau Node.js. Nama proyek hanya boleh menggunakan karakter yang disetujui dan folder yang sudah ada tidak akan ditimpa.
  • Daftarkan folder: gunakan jika proyek sudah dibuat atau berada di luar folder www. Mendaftarkan proyek tidak memindahkan folder.
  • Tugas cepat: pilih Composer install/update, Artisan, PHP server, atau npm task sesuai jenis proyek. Perintah tersebut dapat mengunduh dependensi atau menjalankan skrip; jalankan hanya untuk proyek yang dipercaya.
  • URL lokal: hostname yang didaftarkan adalah pintasan UI. Untuk domain seperti app.test, pastikan konfigurasi virtual host dan hosts Laragon memang tersedia.

              
◉
3. Kontrol layanan dengan aman
Memahami tombol layanan dan status proses.
  • Mulai/Hentikan: mengirim perintah ke executable layanan yang dikenali pada instalasi Laragon yang dipilih. Beberapa konfigurasi kustom mungkin tidak bisa dikendalikan dari UI.
  • Restart: hentikan dan mulai ulang layanan. Operasi ini dapat memutus koneksi aktif. Untuk database, pastikan tidak ada impor, ekspor, atau transaksi penting.
  • Jalur tidak terverifikasi / Proses di luar Laragon: ini merupakan pengaman untuk mencegah UI menghentikan executable lain yang namanya sama. Periksa path instalasi dan hak akses Windows; jangan memaksa menghentikan PID yang tidak dikenal.
  • Port konflik: Apache/Nginx biasanya memakai port HTTP/HTTPS, sedangkan database memakai port terpisah. Periksa layanan lain yang memakai port tersebut sebelum mengubah konfigurasi.
  • Reload konfigurasi: gunakan untuk server yang didukung dan sedang berjalan. Tidak semua jenis layanan menyediakan perintah reload yang aman.

              
⌘
4. Memasang Composer dan tools development
Katalog aplikasi berisi pemasang WinGet dan beberapa installer vendor resmi.
  1. Periksa prasyarat WinGet.
    Pastikan Windows App Installer/WinGet tersedia dan jaringan internet aktif. Instalasi mungkin menampilkan persetujuan atau meminta hak Administrator.
  2. Pasang Composer.
    Di App & Database, cari Composer lalu klik Unduh installer resmi. Installer dibuka dari domain resmi Composer. Saat wizard meminta PHP, arahkan ke versi PHP di folder Laragon, misalnya C:\laragon\bin\php\php-8.x.x\php.exe. Setelah selesai, tutup dan buka ulang terminal serta SXL Cover agar PATH baru terbaca.
     
  3. Pasang Node.js LTS.
    Node.js menyediakan node dan npm. Yarn, pnpm, dan Bun bisa dipasang terpisah sesuai kebutuhan project; jangan memasang beberapa package manager ke proyek tanpa alasan yang jelas.
      
  4. Database server vs database GUI.
    MariaDB, PostgreSQL, dan MongoDB adalah server/engine. HeidiSQL, DBeaver, pgAdmin, MongoDB Compass, Beekeeper Studio, dan DB Browser for SQLite adalah alat klien, bukan pengganti server database.
  5. Perhatikan instalasi portabel Laragon.
    WinGet menginstal aplikasi melalui mekanisme Windows, bukan otomatis ke C:\laragon\bin. Paket bisa mendaftarkan Windows Service atau menambah folder PATH terpisah. Refresh katalog setelah proses selesai dan konfigurasi jalur secara terpisah jika diperlukan.
Catatan Composer: SXL Cover membuka installer resmi; UI tidak menjalankan EXE yang diunduh secara otomatis. Periksa nama file dan publisher sebelum menjalankan installer.

              
DB
5. Profil dan konfigurasi database
Menyiapkan parameter koneksi untuk proyek PHP, Laravel, Node.js, atau aplikasi lain.
  • Buat profil: pilih engine, nama profil, host, port, nama database, dan username. Untuk MySQL/MariaDB biasanya port 3306; PostgreSQL 5432; MongoDB 27017. Periksa port nyata pada servermu.
  • Uji koneksi: saat ini pemeriksaan jaringan hanya memastikan port TCP dapat dijangkau. Ini belum membuktikan username/password benar atau database tersedia. SQLite memakai file lokal sehingga alurnya berbeda.
  • Salin URI: URI dibentuk tanpa password sehingga aman untuk dibagikan sebagai contoh, tetapi tetap periksa host/nama database yang disertakan.
  • Buat .env.example: pilih proyek terdaftar. File hanya dibuat bila belum ada dan tidak menimpa file lama. Password di template tetap kosong; isi rahasia di file .env lokal dan jangan commit ke Git.
  • Buat database/user sesungguhnya: lakukan melalui klien database atau CLI engine menggunakan akun yang sesuai. UI profil saat ini tidak menjalankan SQL untuk membuat database maupun user.
   

              
!
6. Pemecahan masalah
Penyebab umum dan langkah perbaikan yang aman.
WinGet tidak ditemukan
Periksa Microsoft App Installer di Windows, jalankan winget --version di PowerShell, lalu tutup dan buka kembali SXL Cover. Pada beberapa perangkat, ketersediaan WinGet dipengaruhi kebijakan organisasi.
Shutdown MySQL meminta password root
Jika `mysqladmin` menampilkan “Access denied (using password: NO)”, server menolak shutdown tanpa password. Masukkan password root MySQL/MariaDB saat modal SXL Cover muncul. Password tidak disimpan; aplikasi membuat file opsi klien sementara lalu menghapusnya setelah tindakan. Jika password salah, periksa kredensial dan coba lagi. Jangan menghentikan PID database secara paksa.
Composer tidak dikenali setelah dipasang
Pastikan installer Composer menunjuk ke php.exe yang tepat. Tutup semua terminal yang sudah terbuka dan buka kembali. Coba php -v lalu composer --version.
Start/Stop menampilkan jalur tidak terverifikasi
Pastikan Settings → Integrasi Laragon menunjuk ke folder yang benar. Jalankan UI pada tingkat hak akses yang sama dengan proses layanan, bila memang diperlukan. Jangan menghentikan proses eksternal secara paksa.
localhost tidak terbuka atau port bentrok
Pastikan server web berjalan dan periksa log. Cek apakah software lain memakai port yang sama; jangan menjalankan dua web server pada port yang sama tanpa mengatur port berbeda.
URL proyek berakhiran .test tidak ditemukan
Memiliki pintasan URL tidak otomatis membuat DNS/hosts atau virtual host. Konfigurasikan melalui mekanisme Laragon yang didukung lalu reload web server.
Database GUI tidak dapat terhubung
Pastikan server engine telah dipasang dan berjalan, host/port benar, firewall tidak memblokir, database/user telah dibuat, serta kredensial dimasukkan di klien database. Tes port saja bukan tes autentikasi.
Instalasi paket gagal
Buka App & Database → Aktivitas instalasi untuk melihat output WinGet. Pastikan ID paket, sumber WinGet, internet, ruang disk, dan hak akses memenuhi kebutuhan installer. Tutup instalasi lain sebelum mencoba lagi.
Aplikasi mendeteksi proyek dengan salah
Tekan Periksa ulang pada daftar proyek atau refresh aplikasi. Pastikan folder benar-benar ada dan memiliki file proyek seperti composer.json, package.json, atau index.php.

              
⚙
7. Pengaturan, privasi, dan data
Hal penting tentang data yang disimpan aplikasi.
  • Tema dan preferensi disimpan secara lokal di profil pengguna. Aplikasi tidak memerlukan akun cloud untuk memakai fitur dasar.
  • Profil database menyimpan metadata koneksi tetapi tidak menyimpan password.
  • Log dibaca secara read-only dari file yang didukung. Ekspor laporan dapat memuat path folder instalasi; tinjau file sebelum membagikannya.
  • File proyek tidak dihapus ketika proyek dilepas dari daftar. Pembuatan template juga tidak menimpa folder yang sudah ada.
  • Installer pihak ketiga dipasang melalui WinGet atau situs resmi vendor sesuai metode yang ditampilkan. Tinjau persetujuan installer sebelum melanjutkan.
